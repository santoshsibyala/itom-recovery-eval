This consolidated package copies only the selected files from three previously
filtered component manifests, plus v33, the frozen v32 manuscript, and verification wrappers.
Component EXCLUSIONS.md files remain authoritative historical descriptions.

No original reviewer/coordinator archives, individual review returns, private
blinding keys, correspondence, reviewer contact information, kubeconfig/client
credentials, .env files, Git history, account SQLite ledgers, virtual environments
or tool caches are intentionally included. The human-review export contains only
the published aggregate counts; it does not permit a case-by-case independent
re-audit of individual judgments.

Preserved scientific protocols and author approvals contain the author's public
identity. Upstream source contains attribution contacts. These are distinct from
withheld reviewer identities. Invalid execution records, repair receipts and
original/corrected RAC cohorts are intentionally retained and labelled.

A local credential/path/schema scan accompanies the delivery outside this archive.
Pattern/provenance checks cannot prove absence of every possible secret or
identifying free-text statement. The archive is prepared for public release. No private source-file exclusion inventory is bundled.
