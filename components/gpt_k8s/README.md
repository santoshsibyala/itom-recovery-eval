# LLM-on-Kubernetes extension — staged public package

This is a local add-on for the private ITOM artifact repository. It has not been uploaded. It contains the frozen protocol, scientific freeze receipts, implementation, 10 smoke and 50 main records, their journals, analysis and cleanup-repair receipt. Original experimental files are copied byte-for-byte. The raw cleanup error remains recorded; its separate receipt verifies repair without replay.

Run `python3 verify_extension.py` for offline record, journal, classifier, behavior, outcome-table, model and cost verification. No credentials, live cluster or API calls are needed. Original execution scripts retain historical local paths and require environment configuration for a new experiment; they must not be used to overwrite these records.

Historical freeze and analysis manifests reference the original full workspace, including excluded private files. PUBLIC_MANIFEST.json describes the actual released subset. Path references to kubeconfig are provenance, not kubeconfig contents. COST_SUMMARY.json reports aggregate ledger accounting; raw account ledgers are withheld. The full prior-study artifact is separate.
