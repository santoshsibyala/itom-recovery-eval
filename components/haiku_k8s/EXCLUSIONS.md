# Exclusions

This staged extension package contains only synthetic Kubernetes experiments, their protocols, approval/provenance receipts, source code, analyses and additive comparison tables.

Excluded from this package:
- Provider API keys, tokens, credentials, authorization headers and environment files.
- Kubernetes kubeconfig, client certificates and private keys.
- Git history, virtual environments, Python caches, process locks and temporary analysis drafts.
- Mutable SQLite accounting files and their WAL/SHM companions. COST_LEDGER_EXPORT.json provides the verified aggregate accounting; source-ledger hashes are recorded in the manuscript verification record.
- Human-review administrative records, reviewer identities, individual prior-exposure declarations, original review returns, correspondence and the blinding key. No human-review archive is included.

The author's name in protocol approvals is intentionally retained. Experimental run IDs and the invalid-launch incident are retained. Existing SHA manifests describe their original source scopes; PACKAGE_MANIFEST.json describes exactly this staged package. No repository upload or visibility change has occurred.
